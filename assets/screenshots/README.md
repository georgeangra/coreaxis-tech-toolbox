# Capturas de tela

Os arquivos `.svg` desta pasta são **marcadores de posição**.

Para publicar as capturas reais:
1. Abra o programa com dados de **demonstração** (nunca dados reais de clientes).
2. Capture cada módulo em 1280×800 (Win + Shift + S).
3. Salve como `dashboard.png`, `diagnostico.png`, `rede.png`, `atendimento.png`, `windows.png`, `seguranca.png`.
4. No README.md e no site, troque a extensão `.svg` por `.png`.

Antes de publicar, confira se não aparecem: nome do computador, usuário do Windows, IPs, nome da rede Wi-Fi, números de série ou dados de clientes.
