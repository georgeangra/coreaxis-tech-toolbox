# Identidade Visual — CoreAxis Tech Toolbox

<img src="assets/brand/icon-256.png" width="96" alt="Ícone">

## Conceito

A marca nasce da **constelação de nós conectados** do logotipo da CoreAxis Tech: pontos ligados por linhas representam **redes, conexões entre sistemas e automação** — o dia a dia do suporte técnico. O nó maior, com brilho, é o **eixo** (*axis*): o técnico que centraliza e resolve.

**Atributos:** confiável · técnico · organizado · moderno · direto.

| Uso | Forma |

**Descrição curta:** *Diagnóstico, rede, reparo, segurança, automação, inventário e atendimento para Windows — em um único executável.*

## Cores

| Nome | Hex | Uso |
|---|---|---|
| **Turquesa Axis** | `#0BAEC2` | Cor da marca: nós, destaques, ícones, links em fundo escuro |
| Turquesa Claro | `#5FD4E0` | Gradientes, estados de foco, nó terminal |
| Azul Núcleo | `#0B2545` | Fundos de destaque, cabeçalhos |
| Azul Profundo | `#123A63` | Gradientes de fundo |
| Noite | `#060B16` | Fundo principal (tema escuro) |
| Grafite | `#1A2433` | Cartões e superfícies |
| Névoa | `#E3E8EE` | Texto sobre fundo escuro |
| Cinza Ardósia | `#8EA3BF` | Texto secundário |
| Azul Ação | `#1E7BFF` | Botões primários com texto branco (contraste AA) |
| Sucesso / Alerta / Erro | `#22C55E` / `#F5A524` / `#EF4444` | Estados do sistema |

Acessibilidade: texto branco **não** deve ser usado sobre Turquesa Axis em tamanho normal (contraste insuficiente). Para botões com texto branco, use Azul Ação ou Azul Núcleo; o turquesa fica para destaques, ícones e texto sobre fundo escuro.

## Tipografia

- **Interface e site:** Segoe UI Variable / Segoe UI (nativa do Windows), com `system-ui` como alternativa.
- **Código, hashes e comandos:** Cascadia Mono / Consolas.
- Títulos em peso 600–700; corpo em 400; nunca mais de dois pesos por bloco.

## Voz e tom

- Português do Brasil, direto e técnico, sem jargão desnecessário.
- Fala com o técnico como colega: *"Verifique o SHA-256 antes de executar."*
- Transparência acima de marketing: dizer exatamente o que o software faz, acessa e não acessa.
- Nunca prometer o que não está implementado.
